## Projeto

**Descrição:** O projeto criado implementa um sistema de calendário. É possível criar um usuário no página de "signup", entrar no usuário pela página "login" 
e acessar o calendário do usuário pela página "calendar". O calendário começa no mês/ano atual, sendo possível navegar pelos meses (setas para esquerda e direita). 
Também é possível adicionar tarefas (informando o nome, descrição e data da tarefa) as quais são mostradas em uma lista. Qualquer um dos campos de uma tarefa pode ser
alterado na aba "Atualizar Tarefa". Na aba "Remover Tarefa", qualquer tarefa pode ser removida. Ao adicionar tarefas, é possível visualizá-la no calendário recarregando
o calendário (botão ao lado das setas que mudam de mês). As tarefas são visualizadas apenas pelo usuário que as criou.
